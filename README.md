# 动效集萃 · animation.xingheling.cn

一个纯前端（HTML + CSS + JavaScript）的**网页动效集合站**。

根页面是一张「动效集萃」导航页：以卡片形式陈列每一个动效项目，点击卡片进入对应的动效页面。
动效项目各自独立存放在自己的子目录里，互不影响；新增一个动效，只需要加一个目录和一条数据记录。

站点地址：<https://animation.xingheling.cn>

---

## 一、导航页

### 功能

- 以卡片网格陈列所有动效项目，每张卡片包含：封面预览图、标题、副标题、简介、标签，以及「查看动效」入口。
- 整张卡片就是链接，点击即进入对应的动效页面（例如 `/ball-escape/`）。
- 列表由数据驱动：所有项目信息集中在 `assets/js/projects.js` 的 `window.SITE_DATA` 里。
  新增动效时只需在 `projects` 数组中追加一条记录，并把封面图放进 `assets/covers/`，页面结构无需改动。
- 页脚是一行居中的「星河绫 · GitHub」：`GitHub` 带一枚章鱼猫图标，点击在新标签页打开仓库 `https://github.com/tony-he-xhxk/xhl-anim`（文案、链接、图标同样在 `assets/js/projects.js` 里维护）。

### 视觉与页面动效

整体是**深色 + 霓虹紫青**的科技感基调，页面自身也带有一层轻量动效：

- 标题为流动的渐变文字，缓慢左右游走；
- 卡片按顺序错峰入场（由上浮淡入组成）；
- 鼠标悬浮时卡片抬升、浮现霓虹渐变描边，并有高光扫过；
- 光标在卡片上移动时，会跟随指针产生一圈径向光晕（仅在桌面精细指针设备上启用）；
- 背景是缓慢漂移的网格与轻微闪烁的星点，外加两团缓慢浮动的辉光。

### 响应式与可访问性

- 宽屏下多列卡片，窄屏自动收为单列；封面图、字号、间距都随视口自适应。
- 卡片与页脚链接支持键盘聚焦，焦点样式可见；封面图带有替代文本。
- 若访问者系统开启了「减弱动态效果」（`prefers-reduced-motion`），页面会关闭入场、漂移、扫光等装饰性动画，只保留内容本身。

## 三、小球逃离环形圈：动画规则

### 一句话概括

小球被困在层层同心圆环的中心，每层圆环上都有一个旋转的缺口。小球在环内不断撞击、反弹，
每撞一次，外侧就会多长出新的圆环；只有对准缺口穿出去，才能一层层突破，直到逃出全部圆环。

### 规则细节

1. **圆环**：从中心向外是一层层同心圆环，每层都有一个缺口。所有圆环都在持续旋转，各层的转动方向与快慢互不相同，但遵循固定规律（逐层反向，速度按正弦函数轻微调制），不是随机乱转。
2. **小球**：从中心出发，方向随机；在环内做恒速直线运动，速度大小保持不变。
3. **撞击 → 增环**：小球撞在圆环的实体部分会被弹开，并在**最外侧新增圆环**（默认每次 +1 层，可调 1~3 层）。
4. **穿出 → 碎裂**：小球若正好撞进缺口的位置，就会穿过这一层，该层随即**碎裂**并散落。如果它一口气穿过好几层，**被穿过的每一层都会各自碎裂**（每层都有独立的碎片与扩散冲击环）。
5. **穿出之后的一次撞击不增环**：紧跟在「穿出」之后的那次撞击是“免费”的，不会新增圆环；其余撞击照常增环。也就是「撞击1 → 撞击2」时撞击2增环，而「撞击1 → 穿出 → 撞击2」时撞击2不增。
6. **缺口会越撞越大**：每次撞击都会让所有圆环的缺口角度略微变大（约 4°／次，最大到 330°）。所以前期很难穿出，越到后期越容易突破。
7. **数量上限**：圆环总数封顶 100 层，达到后不再新增（出于性能与画面可读性考虑）。
8. **结束**：当小球穿出最外层的圆环，即「逃出全部圆环」，动画结束并展示结算——用时、撞击次数、穿出层数。
9. **倒计时挑战**（可选，默认关闭）：开启后设定限时，时间耗尽仍未逃出即判定失败，并展示已穿出的层数与剩余层数。

### 可调参数

| 参数 | 范围 | 说明 |
| --- | --- | --- |
| 圆环层数 | 3 ~ 24 | 初始层数。越多越难，也越耐看 |
| 旋转速度 | 0 ~ 2.00× | 所有圆环的转动速度倍率 |
| 缺口大小 | 8° ~ 60° | 初始缺口角度。越大越容易穿出 |
| 每次碰撞新增层数 | 1 ~ 3 | 每次撞击在最外侧新增的层数。越多越难 |

参数调整后会重新发一局；若当时没有在播放，则停留在静止的待开始状态，方便连续调参。

### 操作方式

- 进入页面先看到居中的说明遮罩，点「**进入动画**」关闭（此时动画尚未开始）。
- 点「**开始**」播放动画；播放中按钮变为「**暂停**」，暂停后变为「**继续**」。
- 「**重开**」立即重新发一局并开始播放。
- 结算后可选择「再来一次」「调整参数」（关掉遮罩回到可调参状态）或「返回集萃」。
- 键盘：`空格` 开始 / 暂停，`R` 重开，遮罩显示时 `回车` / `空格` 等于「进入动画」。
- 窄屏（≤900px）播放时会自动收起调节栏，只在底部保留一行参数与「暂停 / 重开」；暂停后调节栏会自动回来。

### 平衡

默认参数经过离线模拟批量调校（数百局随机种子）：**都能逃出全部圆环，但不轻松**——
通常需要几十次撞击、二十秒上下才通关。四个参数都会明显影响通关时长，可以按手感自行调整。

## 四、小球逃离环形圈：实现逻辑

### 技术形态

纯静态、无框架、无构建步骤，全部使用经典脚本（`<script src>`）配合全局命名空间 `window.BE`，
因此直接用浏览器打开或用任意静态服务器托管都能运行。画面由 **Canvas 2D** 绘制。
所有可调项与常量集中在 `ball-escape/js/config.js`，界面上的滑杆只覆盖其中四个可调项。

### 模块划分

| 文件 | 职责 |
| --- | --- |
| `config.js` | 全部常量与默认参数（世界尺寸、上限、相机、粒子、配色、默认值） |
| `ring.js` | 圆环：半径、缺口角、角速度规律；初始生成与向外新增 |
| `ball.js` | 小球：位置、速度；速率随活动半径缩放 |
| `physics.js` | 每帧的步进：直线运动、与圆环的碰撞 / 穿缺口 / 增环 / 碎裂判定 |
| `particles.js` | 碎裂碎片与冲击环的生成、演化 |
| `camera.js` | 缩放（离散热更新）与死区松弛跟随 |
| `render.js` | Canvas 绘制：圆环、碎片、冲击环、拖尾、小球 |
| `ui.js` | 参数面板、HUD、开始 / 结算遮罩、窄屏底部一行参数 |
| `main.js` | 状态机与主循环，把上面这些串起来 |

### 关键机制

**世界坐标与圆环。** 所有计算发生在固定的“世界坐标”里：第 k 层圆环半径 `r_k = r0 + k · 环距`，
环距恒定、永不压缩，小球半径也是常数。画面缩放只由相机负责，物理本身不受屏幕尺寸影响。

**碰撞判定。** 把一帧内的运动看成一条线段，与当前最内层存活圆环的“碰撞圆”求交（线段—圆判别式），
取交点后算它的极角：若落在该层缺口的角度区间内就是「穿出」，否则按该点的径向法线做镜面反射。
反射后再叠加一个 ±16° 的随机偏转，并限制反射方向与内向法线的夹角不超过 72°——
前者是为了打破“正圆镜面反射会让弦角不变、小球一直沿同一条直径来回”的退化轨迹，
后者是为了避免临界掠射时小球贴着环壁高频空撞。

**节奏恒定。** 小球速率取 `speedFactor × 当前最内层存活圆环半径`。由于活动空间随突破层数变大，
这样的正比关系能让小球在屏幕上的飞行节奏始终一致，不会越到后面越像慢动作。

**一帧内连穿多层。** 物理步进用循环处理“本帧剩余时间”：穿过一层后立即用剩下时间继续判断下一层，
所以一次冲刺可以连穿数层并成串碎裂（迭代有上限，避免极端情况下卡住）。

**碎裂与冲击环。** 每层碎裂时生成 20 段**真实弧段**：它们出生瞬间与原圆环完全重合，
之后按**刚体运动**（沿径向位移 + 绕出生点自转）飞散、约 1.2 秒内淡出；
同时补一圈约 0.38 秒的扩散冲击环，让“这一层碎了”一眼可见。

**相机。** 缩放**只在离散事件发生时更新**（新增圆环 / 圆环碎裂 / 窗口尺寸变化），
目标是让最外环刚好入镜，帧间只做平滑逼近，不做逐帧追踪；
平移则使用「中心 70% 死区」的松弛跟随——小球在中心区域内时画面完全不动，越界后才缓慢移动焦点，
避免画面时刻在漂。窗口尺寸变化时会立即重绘一帧，不会出现空白闪烁。

**画面。** 圆环按层号做彩虹色相映射（紫→蓝→青→绿→黄→红循环），带一层柔光描边；
小球带拖尾与光晕；背景是径向渐变。为了性能：设备像素比上限 2、碎片总量上限约 900、
每层碎片 20 段、圆环数量上限 100 层。
